# 📸 Instant

A modern and minimal photo editor built with React and Vite.

Instant lets users upload a photo, position and zoom it inside an instant-print frame, add a custom caption, choose a font, and download the final result.

---

## ✨ Features

- 📸 Upload photos
- 🖼️ Instant-print style photo frame
- 🖱️ Drag to reposition images
- 🔍 Image zoom control
- ✍️ Custom photo captions
- 🔤 Multiple font options
- 💾 Editor state persistence
- 🔄 Editor state survives page refresh
- 🔒 Editor page protection
- 🏠 Automatic return to Home when no saved edit exists
- 🖼️ Animated homepage image slideshow
- ✨ Smooth image transitions
- 📱 Responsive design
- 🎨 Minimal premium UI
- ❌ Custom 404 error page

---

## 🧠 Tech Stack

- ⚛️ React
- ⚡ Vite
- 🧭 React Router DOM

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```
git clone https://github.com/your-username/instant.git
```

---

### 2️⃣ Navigate to Project Folder

```
cd instant
```

---

### 3️⃣ Install Dependencies

```
npm install
```

---

### 4️⃣ Start Development Server

```
npm run dev
```
